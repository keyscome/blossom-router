# Blossom Router project description

## GitHub description

Route AI prompts across local and cloud models with one lightweight, configurable CLI.

## Short pitch

Blossom Router is a lightweight Go CLI for macOS that helps developers spend premium AI quota deliberately. Use `bloom` to send routine prompts to local Ollama models, direct normal and coding work to configurable compatible endpoints, reserve stronger models for difficult tasks, or preview a deterministic automatic route before any request is made.

## Full description

AI work rarely needs the strongest model every time. Blossom Router provides one small command-line interface over local, cheap, normal, strong, and code-oriented provider slots. Every cloud model, endpoint, and credential remains configuration-driven. The automatic router uses visible keyword and length rules rather than an extra classifier call, so routing itself does not consume model quota.

The initial release is intentionally narrow: one Go binary, one YAML configuration file, stdin and argument input, and the OpenAI-compatible chat-completions protocol. It has no hidden retries, automatic fallback, telemetry, conversation database, RAG, MCP, or agent framework.
