# Visual assets

The images in this directory are original Blossom Router project artwork generated for this repository with OpenAI's built-in image generation tool on 2026-08-10.

- `blossom-router-hero.jpg`: text-free 16:9 key visual for README and repository presentation.
- `blossom-router-poster-en.jpg`: English launch poster.
- `blossom-router-poster-zh-CN.jpg`: Simplified Chinese launch poster.

The shared visual direction is a luminous five-petal blossom connected to five model-route nodes on a charcoal background. The five nodes represent local, cheap, normal, strong, and code routes. No third-party logos or source images were used.
